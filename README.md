## 📌 Proje Hakkında

Bu proje sayesinde kullanıcılar;
- Film veya dizileri arayabilir,
- Kendi “izleme listesine” ekleyebilir,
- İzlemek istediklerini kaydedebilir.

React ile basit, temiz ve hızlı bir kullanıcı arayüzü sunar. :contentReference[oaicite:2]{index=2}

## 🧰 Kurulum

Projeyi kendi bilgisayarında denemek için:

```bash
# Repo'yu klonla
git clone https://github.com/fatih-candir/React-Watchlist-Project.git

# Klasöre gir
cd React-Watchlist-Project

# Paketleri yükle
npm install

# Projeyi çalıştır
npm start
